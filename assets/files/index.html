POST /api/upload
Binary Stream / Multipart
Upload binary file payload directly into storage.
curl -X POST http://localhost:8081/api/upload --data-binary @sample.pdf
POST /api/install-apk
Header: x-apk-name
Remote package installation stream daemon.
curl -X POST http://localhost:8081/api/install-apk -H "x-apk-name: test.apk" --data-binary @test.apk
